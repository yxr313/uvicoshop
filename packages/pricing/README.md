# @uvico/pricing

Fuente única de verdad para precios, comisiones y políticas de reembolso de UVICO.

## Estructura

- `plans.ts` — 4 planes, precios mensual/anual, descuento del 17%.
- `founder.ts` — intro del Plan Fundador ($1x3), 500 cupos, trial de 7 días.
- `dropshipping.ts` — comisión del 5%, split de venta, frecuencias de liberación, chargeback.
- `refunds.ts` — política de reembolsos de dos niveles (cupón vs. dinero).
- `display.ts` — formateo USD/VES.
